Pebble Design System · Component

Button

Four tiers, one geometry. Every button in Pebble is the same 52 px pill; hierarchy is carried entirely by colour, and every state is a change in opacity. No shadows, no scale, no glow.

/* Base — geometry is identical across all four tiers */
.btn {
  appearance: none;
  display: inline-flex;
  align-items: center;
  justify-content: center;
  box-sizing: border-box;
  width: 100%;
  height: var(--control-h-l);            /* controlHeight.l — 52 */
  padding: 0 24px;                      /* spacing.24 */
  border: none;
  border-radius: var(--radius-full);     /* radius.full */
  background: transparent;
  box-shadow: none;
  /* typeText.paragraphP1Semibold */
  font-family: var(--font-text);
  font-size: 15px;
  line-height: 22px;
  font-weight: var(--weight-semibold);
  letter-spacing: var(--ls-normal);
  white-space: nowrap;
  cursor: pointer;
  transition: opacity 120ms ease;
}
.btn--m { height: var(--control-h-m); }   /* controlHeight.m — 44 */

/* Tiers — colour only */
.btn--primary {
  background: var(--metric-readiness);
  color: var(--text-on-accent);          /* textColor.onAccent */
}
.btn--secondary {
  border: var(--border-thin) solid var(--metric-readiness);
  color: var(--metric-readiness);
}
.btn--tertiary {
  color: var(--text-2);
  font-weight: var(--weight-medium);      /* p1.medium */
}
.btn--destructive {
  color: var(--negative-text);
  font-weight: var(--weight-medium);      /* p1.medium */
}

/* States — opacity only */
.btn--primary:not([disabled]):hover      { opacity: .9; }
.btn--primary:not([disabled]):active     { opacity: .8; }
.btn--secondary:not([disabled]):hover    { opacity: .75; }
.btn--secondary:not([disabled]):active   { opacity: .6; }
.btn--tertiary:not([disabled]):hover,
.btn--destructive:not([disabled]):hover  { opacity: .7; }
.btn--tertiary:not([disabled]):active,
.btn--destructive:not([disabled]):active { opacity: .55; }
.btn[disabled] { opacity: .45; cursor: default; }

.btn:focus-visible { outline: 2px solid var(--metric-readiness); outline-offset: 4px; }

@media (prefers-reduced-motion: reduce) {
  .btn { transition: none; }
}

Still off-system: this sheet's own chrome uses JetBrains Mono for token paths and code — the system has no mono face — and the 40 px masthead sits above the app's 24 px h1 ceiling, since this is a desktop document rather than an app screen. Both are document furniture, not component values. :focus-visible is an addition to the brief: it uses --metric-readiness at 2px with a 4px offset, so drop it if focus is ever handled globally.
