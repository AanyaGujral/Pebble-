Timeline

0 – 0.6 sStreaks start arriving from the rim, staggered. Arcs fade up and begin their sweep. Core is a faint breath at 40% scale.
0.6 – 1.8 sSecond pass of streaks keeps the flow going. Arcs contract inward. Dark wash reaches about a third of full; blur about a third.
1.95 sImpact — the core flashes to 110% and one ring pops outward.
2.2 – 3.0 sArcs and streaks are gone. Core settles to a soft glow at 80% opacity. Wash and blur reach full.
3.0 s onwardHeld end frame: dark, blurred centre with a teal glow. Content fades in over it (.ai-reveal.is-revealed).

Classes

.ai-loadThe overlay. Transparent, absolutely positioned, inherits the card's radius, ignores pointer events.
.is-runningOn .ai-load — starts the 3 s clock. Every layer holds its last frame when it finishes.
.is-settledOn .ai-load — jumps straight to the held end frame with no motion. Use it if the card re-renders mid-request, and it is what reduced motion falls back to.
.ai-card__contentOn the card's own content. Puts it above the overlay so the dark blurred centre acts as a backdrop instead of smearing the text. Leave it off if you want the loader to frost stale data while it refreshes.
.ai-reveal / .is-revealedOn the text that waits for the data, and the class you add when it arrives.

Knobs

--ai-durTotal run time. Default 3000ms. Everything is expressed as a share of this, so changing it retimes the whole animation.
--ai-sizeDiameter of the gathering area. 200px for a full-width card, 120px for a compact one.
--ai-blurEnd-frame blur radius. Default 9px.
--ai-darkEnd-frame darkness, 0–1. Default 0.84.
